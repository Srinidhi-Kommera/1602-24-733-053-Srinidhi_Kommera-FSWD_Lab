# React Lab Programs

Three React programs in one Vite project, switchable from the tabs at the top.

1. Employee table with `map()`, `key` and conditional row highlighting (salary above 50000)
2. Event handling: mouse over, mouse out, double click, `onKeyDown`, and a form using `preventDefault()`
3. Student registration form with controlled components and validation

## Run locally

```
npm install
npm run dev
```

Open the URL printed in the terminal (usually http://localhost:5173).

## Build

```
npm run build
npm run preview
```
